# Google Merchant Center - Guía rápida

## Feed
URL: `https://peruanadeinformatica.com.pe/feed/google-merchant.xml` o `/api/feed/google-merchant.xml`

## Pasos
1. Crear cuenta en Google Merchant Center
2. Verificar y reclamar sitio web
3. Subir feed (Productos > Feeds) usando la URL del XML
4. Activar Free listings
5. Revisar diagnóstico y corregir errores

## Recomendado
- Incluir solo productos con stock > 0
- Usar precios correctos en PEN
- Asegurar imágenes accesibles públicamente
