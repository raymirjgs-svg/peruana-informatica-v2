Primeros pasos

Cómo acceder al panel

### URL de acceso

El panel de administración está disponible en:

🌐

Dirección del panel

      `https://peruanadeinformatica.com.pe/admin/login`

### Iniciar sesión

**Abra el navegador** (Chrome, Edge o Firefox recomendados).

**Ingrese la URL** del panel en la barra de direcciones.

**Escriba su correo electrónico** y **contraseña** de administrador.

**Haga clic en "Ingresar"** y será redirigido al panel principal.

### Navegación

El panel tiene una barra lateral izquierda con todos los módulos. Haga clic en cualquier ítem para acceder a esa sección. En dispositivos móviles la barra se puede ocultar con el botón de menú.

⚠️

Sesión expirada

      Si aparece el mensaje "Tu sesión ha expirado", simplemente vuelva a iniciar sesión con sus credenciales. Las sesiones duran 30 días de uso continuo.

### Cerrar sesión

Para cerrar sesión de forma segura, haga clic en su nombre de usuario en la parte inferior de la barra lateral y seleccione **"Cerrar sesión"**. Siempre cierre la sesión al usar computadoras compartidas.

Dashboard

El Dashboard es la pantalla principal del panel. Muestra un resumen ejecutivo del rendimiento del negocio en tiempo real.

Módulo 3

Productos

/admin/products

El módulo de Productos permite gestionar todo el catálogo: crear, editar, eliminar y organizar los productos de la tienda.

### Lista de productos

La tabla principal muestra todos los productos con las siguientes columnas:

| Columna |Descripción |

| Código |Identificador interno único del producto |

| Nombre |Nombre del producto y miniatura de imagen |

| Precio |Precio de venta actual en soles (S/) |

| Stock |Unidades disponibles en inventario |

| Marca |Marca del fabricante |

| Categoría |Categoría a la que pertenece |

| Etiquetas |Destacado / Nuevo / Liquidación (toggles rápidos) |

| Acciones |Editar o eliminar |

### Filtrar y buscar

- Use la **barra de búsqueda** para buscar por nombre o código.

- Use el **filtro de categoría** para ver productos de una categoría específica.

- Use los **toggles de etiquetas** para filtrar por Destacado, Nuevo o Liquidación.

### Etiquetas especiales

Cada producto puede tener hasta 3 etiquetas que lo destacan en el sitio web:

⭐

Destacado

Aparece en la sección "Productos destacados" del inicio

🆕

Nuevo

Aparece en la sección "Nuevos productos" del inicio

🔖

Liquidación

Aparece en la sección "Liquidación" del inicio

Para activar o desactivar una etiqueta, haga clic en el ícono correspondiente en la fila del producto. El cambio se guarda automáticamente.

### Crear un producto nuevo

Haga clic en el botón **"+ Nuevo producto"** para abrir el formulario de creación.

**Información básica:** Ingrese el código interno, nombre del producto y descripción detallada.

**Precio y stock:** Ingrese el precio de venta (S/) y la cantidad en inventario.

**Clasificación:** Seleccione la categoría, subcategoría y marca del producto.

**Imágenes:** Suba una o varias imágenes del producto. La primera será la imagen principal.

**SEO (opcional):** Complete el título SEO, descripción y palabras clave para mejorar el posicionamiento en Google.

**Guardar:** Haga clic en "Crear producto" para publicarlo en la tienda.

### Campos del formulario

Código interno*

Código único de referencia (ej: LPT-001, MON-HP24)

Nombre*

Nombre completo del producto tal como aparecerá en la tienda

Descripción*

Descripción detallada con especificaciones técnicas

Precio*

Precio de venta en soles peruanos (S/). Sin el símbolo.

Stock*

Unidades disponibles actualmente

Categoría*

Categoría principal (ej: Laptops, Monitores, Impresoras)

Subcategoría

Subcategoría específica dentro de la categoría elegida

Marca*

Fabricante o marca del producto

Imágenes

Fotos del producto. Formatos: JPG, PNG, WebP. Máx 5MB por imagen.

Título SEO

Título para motores de búsqueda (máx 60 caracteres)

Descripción SEO

Resumen para Google (máx 160 caracteres)

Palabras clave

Separadas por coma: laptop hp, computadora portátil, notebook

### Editar un producto

Haga clic en el ícono de lápiz ✏️ en la fila del producto. Se abrirá el mismo formulario con los datos actuales. Modifique lo necesario y haga clic en **"Guardar cambios"**.

### Eliminar un producto

Haga clic en el ícono de basura 🗑️. Aparecerá una confirmación antes de eliminar. **Esta acción no se puede deshacer.**

⚠️

Antes de eliminar

      No elimine productos que estén en pedidos existentes. En su lugar, cambie el stock a 0 para que no aparezca disponible.

Módulo 4

Categorías

/admin/categories

Las categorías organizan los productos en grupos lógicos. Cada categoría puede tener subcategorías para una clasificación más detallada.

### Estructura de categorías

El sistema tiene dos niveles:

- **Categorías principales** — ej: Laptops, Impresoras, Monitores

- **Subcategorías** — ej: dentro de "Laptops": Gaming, Ultrabooks, Empresarial

### Crear una categoría

**Nombre:** Ingrese el nombre de la categoría (ej: "Teclados").

**Slug:** Se genera automáticamente (ej: "teclados"). Puede modificarlo si lo desea.

**Aparece en menú:** Active esta opción para que sea visible en la navegación del sitio.

**SEO:** Opcionalmente complete el título y descripción SEO para esa categoría.

**Guardar.**

### Gestionar subcategorías

Haga clic en el ícono de expandir ▶ junto a una categoría para ver y gestionar sus subcategorías. Desde ahí puede crear, editar, reordenar o eliminar subcategorías.

💡

Slug automático

      El "slug" es la versión URL-amigable del nombre (sin espacios ni caracteres especiales). Se genera automáticamente al escribir el nombre, pero puede editarlo manualmente.

Módulo 7

Pedidos

/admin/orders

El módulo de Pedidos gestiona todo el ciclo de vida de un pedido: desde que el cliente realiza la compra hasta la emisión de la boleta/factura.

### Información de cada pedido

| Campo |Descripción |

| ID de pedido |Número único del pedido |

| Cliente |Nombre, correo y teléfono del comprador |

| Total |Monto total del pedido en S/ |

| Estado del pedido |Pendiente / En proceso / Completado / Cancelado |

| Estado de pago |Pendiente / Verificado / Rechazado |

| Tipo de comprobante |Boleta o Factura |

### Flujo de procesamiento de un pedido

1

Ver comprobante

Revisar foto del voucher del cliente

2

Verificar pago

Aprobar o rechazar el comprobante

3

Subir factura

Cargar boleta/factura en PDF

4

Descargar

El cliente descarga su documento

### Paso a paso: Procesar un pedido

**Revisar el comprobante de pago:** Haga clic en el pedido para ver la foto del voucher de transferencia que subió el cliente.

**Verificar en su banco:** Confirme que el depósito o transferencia aparezca en su cuenta bancaria.

**Aprobar o rechazar:**

- Si el pago es correcto: haga clic en **"Verificar pago"** ✅

- Si el pago es incorrecto o falso: haga clic en **"Rechazar"** ❌ (se notifica al cliente)

**Generar y subir el comprobante:** Una vez aprobado el pago, genere la boleta o factura según solicite el cliente y súbala en formato PDF haciendo clic en **"Subir factura"**.

**El cliente recibe notificación** y puede descargar su comprobante desde su cuenta.

✅

Buena práctica

      Procese los pedidos dentro de las 24 horas de recibidos. Los clientes esperan confirmación rápida. Puede usar el Dashboard para ver cuántos pedidos están pendientes cada vez que ingrese al panel.

Los cupones permiten ofrecer descuentos especiales a los clientes mediante un código que ingresan al momento de comprar.

Haga clic en **"+ Nuevo cupón"** y complete los campos:

Código*

El código que el cliente ingresa (ej: VERANO20, BIENVENIDO10). Solo letras mayúsculas y números.

Descripción

Texto descriptivo para uso interno (no visible al cliente)

Tipo de descuento*

Porcentaje (ej: 20% off) o Monto fijo (ej: S/ 50 de descuento)

Valor*

Número del descuento: 20 para 20%, o 50 para S/ 50

Compra mínima

Monto mínimo del carrito para aplicar el cupón (ej: S/ 200)

Límite de usos

Cuántas veces puede usarse en total. Vacío = ilimitado.

Fecha de expiración

Fecha límite para usar el cupón. Vacío = sin vencimiento.

Activo

Toggle para activar/desactivar sin eliminar

💡

Estrategia de cupones

      Use cupones de bienvenida (10–15% off) para primeras compras, y cupones especiales para fechas como Black Friday, Navidad o aniversario de la empresa.

Módulo 14

Marketing por email

/admin/marketing

Envíe campañas de correo electrónico masivas a todos sus clientes registrados desde el panel.

### Cómo enviar una campaña

**Ver destinatarios:** El sistema muestra automáticamente cuántos clientes recibirán el correo.

**Asunto:** Escriba el asunto del correo (ej: "¡Ofertas de Navidad — hasta 30% OFF!").

**Mensaje:** Redacte el cuerpo del correo. El sistema incluye automáticamente el nombre del cliente.

**Vista previa:** Revise cómo se verá el correo antes de enviarlo.

**Enviar:** Haga clic en "Enviar campaña". Aparecerá una confirmación. Confirme para iniciar el envío masivo.

**Resultados:** El sistema mostrará cuántos correos se enviaron exitosamente y cuántos fallaron.

⚠️

Use con responsabilidad

      Envíe campañas solo cuando tenga contenido de valor para los clientes (ofertas reales, novedades, eventos). El exceso de correos puede causar que sus clientes cancelen la suscripción o marquen los mensajes como spam.

El módulo muestra una vista previa de cómo se verá la barra de anuncios con el fondo rojo degradado característico de la marca.

### Activar / desactivar anuncios

Cada anuncio tiene un toggle para activarlo o desactivarlo sin necesidad de eliminarlo. Esto es útil para anuncios estacionales que puede querer reutilizar.

Módulo 18

Accesos rápidos de categorías

/admin/quick-categories

Los accesos rápidos son botones con ícono que aparecen debajo del carrusel principal, permitiendo a los visitantes navegar rápidamente a las categorías más populares.

### Campos

Ícono

Emoji representativo (ej: 💻 para Laptops, 🖨️ para Impresoras)

Etiqueta

Texto del botón (ej: "Laptops", "Monitores")

Enlace

URL a donde lleva el botón (ej: /productos?categoria=laptops)

Orden

Posición del botón en la fila

### Previsualización

El módulo incluye una vista previa visual que muestra cómo se ven los botones de acceso rápido antes de guardar los cambios.

Módulo 23

Estado del sistema

/admin/system

Panel de monitoreo técnico del servidor y los servicios. Útil para detectar problemas de conectividad o rendimiento.

### Servicios monitoreados

| Servicio |Qué monitorea |

| 🗄️ Base de datos (MySQL) |Estado de conexión y tiempo de respuesta |

| 🤖 Google Gemini API |Si la IA para el blog está configurada |

| 🔐 Google OAuth |Si el login con Google está activo |

| 🔗 API externa ERP |Conectividad con sistemas externos |

### Recursos del servidor

- **Tiempo activo (uptime)** — cuánto tiempo lleva el servidor corriendo sin reinicios

- **Memoria usada** — RAM del proceso de la aplicación

- **Memoria del sistema** — RAM total del servidor

### Indicadores de estado

- ● Operativo — servicio funcionando correctamente

- ● Error — servicio con problemas, contacte a soporte técnico

- ● Advertencia — servicio funciona pero con limitaciones

El sistema se actualiza automáticamente cada 30 segundos. También puede hacer clic en **"Actualizar"** para forzar una verificación inmediata.

🚨

Si ve un servicio en rojo

      No intente solucionar problemas técnicos del servidor por su cuenta. Contacte a su proveedor de soporte técnico con una captura de pantalla de esta pantalla.
